Getting started
Put any command you would type into the FiveM or RedM console into On Press. The game has to be running on this PC.
Syntax
e sit;me sits down runs several, one after another
e think;;e c waits 500ms between them
e think;{200ms};e c waits a specific time
Raise No. of states in Advanced Settings to cycle a button through several commands.

How it works
Ticking "Show response" appends a token like @fxid:ab12cd34 to the command, then watches the console for a line containing it. The token is stripped and whatever remains is shown on the button.
Your command has to cooperate
Pull the token off the end of the arguments and print it back with the value:
local t = args[#args]:match("^@fxid:") and table.remove(args)
if t then print(("%s %s"):format(t, value)) end
Only tick it for commands you have updated. Anything else receives @fxid:... as an unexpected extra argument.
Get Value
Runs when the button appears (plugin start, profile load, page switch) so it shows the current value rather than a stale one. Needs the same token handling.
On a dial
The value goes on the touch strip instead of the title. Print a trailing % and it draws a progress bar.
Nothing back within the timeout leaves the button unchanged. Full guide: the wiki.
